# Dependencies
These dependencies are required:
- sqlite3
- libcurl
- qt6 (only if you're building the GUI executable, which in most cases you will be.)

## Windows
The recommended way of building the project is using MSYS2, which is a program that provides a Unix-like environment on Windows so that you can use package managers and all that jazz. It comes with Pacman, which is a package manager that you may recognize if you've ever used Arch Linux before.
