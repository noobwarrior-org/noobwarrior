# hash
Hashing for passwords, tokens and data. Results are lowercase hexadecimal strings.

# Functions
| Function | Description |
| --- | --- |
| [GenerateToken](/api/luau/libraries/hash/GenerateToken) | Makes a random token for sessions or one-time links. |
| [HashPassword](/api/luau/libraries/hash/HashPassword) | Hashes a password for storage. |
| [VerifyPassword](/api/luau/libraries/hash/VerifyPassword) | Checks a password against a stored hash. |
| [Sha256](/api/luau/libraries/hash/Sha256) | Computes the SHA-256 digest of a string. |
