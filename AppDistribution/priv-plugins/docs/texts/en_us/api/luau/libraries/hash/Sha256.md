```luau
hash.Sha256(data: string): string
```

# Description
Computes the SHA-256 digest of a string. Don't use it for passwords: it is fast, which makes guessing cheap. Use [HashPassword](/api/luau/libraries/hash/HashPassword) for those.

# Arguments
1. `data: string`: the bytes to hash.

# Returns
The digest as 64 hexadecimal characters.

# Example
```luau
print(hash.Sha256("hello"))
-- 2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824
```
