# Welcome to the documentation for noobWarrior
Hello. This is the first page of the documentation for noobWarrior, a program that aims to be an all-in-one, self-contained toolkit for everything Roblox.

These pages cover everything to do with noobWarrior: its history, how to use it, how it works under the hood and why it works that way, how to make content with it, and so on. Basically everything.

First, I'd like to tell you how noobWarrior started and why we made it. If you don't care about that, skip ahead to the Introduction page.

# Where did the name come from?
The name comes from ArchiveTeam's "ArchiveTeam Warrior," a program that hands archiving work off to volunteers' computers. I figured a Roblox preservation project should have a similar name, and since new Roblox players are commonly called noobs, it became noobWarrior.
